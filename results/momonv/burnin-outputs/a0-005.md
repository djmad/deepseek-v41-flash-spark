# task 5: Write a Python class for a thread-safe bounded queue using threading.Condition.

```python
import threading
from collections import deque


class BoundedQueue:
    def __init__(self, capacity):
        if capacity <= 0:
            raise ValueError("capacity must be positive")
        self.capacity = capacity
        self._queue = deque()
        self._cond = threading.Condition()

    def put(self, item, timeout=None):
        with self._cond:
            if not self._cond.wait_for(
                lambda: len(self._queue) < self.capacity, timeout
            ):
                raise TimeoutError("put timed out")
            self._queue.append(item)
            self._cond.notify_all()

    def get(self, timeout=None):
        with self._cond:
            if not self._cond.wait_for(lambda: self._queue, timeout):
                raise TimeoutError("get timed out")
            item = self._queue.popleft()
            self._cond.notify_all()
            return item

    def __len__(self):
        with self._cond:
            return len(self._queue)
```

`threading.Condition` guards all mutations of the internal deque, and `wait_for` blocks producers when full and consumers when empty. `notify_all` wakes both sides so no thread is starved after a state change.
