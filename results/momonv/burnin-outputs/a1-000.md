# task 3: Write a Python async function that fetches several URLs concurrently with a limit of 3 at a time using asyncio.Semaphore (assume an async fetch(url) exists).

```python
import asyncio

async def fetch_all(urls, limit=3):
    sem = asyncio.Semaphore(limit)
    async def worker(url):
        async with sem:
            return await fetch(url)
    return await asyncio.gather(*(worker(u) for u in urls))
```

A semaphore caps concurrency at 3, and `asyncio.gather` runs all workers concurrently while preserving result order.
