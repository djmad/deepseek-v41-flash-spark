# task 7: Write a Python generator that yields sliding-window averages over an iterable of numbers.

```python
from collections import deque
from itertools import islice

def sliding_average(iterable, window):
    if window <= 0:
        raise ValueError("window must be positive")
    it = iter(iterable)
    buf = deque(islice(it, window), maxlen=window)
    if len(buf) < window:
        return
    total = sum(buf)
    yield total / window
    for x in it:
        total += x - buf[0]
        buf.append(x)
        yield total / window
```

The generator keeps a fixed-size `deque` and a running sum, so each new average is computed in O(1) time after the initial window fill.
