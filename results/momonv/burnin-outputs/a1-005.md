# task 8: Write a Python function that validates an IPv4 address string without using the ipaddress module.

```python
def is_valid_ipv4(ip):
    parts = ip.split('.')
    return len(parts) == 4 and all(
        p.isdigit() and (p == '0' or not p.startswith('0')) and 0 <= int(p) <= 255
        for p in parts
    )
```

Splits on dots, checks exactly four parts, each a digit-only string with no leading zeros (except `"0"`) and within `0–255`.
