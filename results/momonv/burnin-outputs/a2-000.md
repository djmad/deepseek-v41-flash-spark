# task 6: Write a Python function that topologically sorts a dependency dict and raises on cycles.

```python
from collections import deque

def topo_sort(deps):
    graph = {node: set(edges) for node, edges in deps.items()}
    for edges in deps.values():
        for e in edges:
            graph.setdefault(e, set())
    indeg = {n: 0 for n in graph}
    for n, edges in graph.items():
        for e in edges:
            indeg[e] += 1
    queue = deque(n for n, d in indeg.items() if d == 0)
    order = []
    while queue:
        n = queue.popleft()
        order.append(n)
        for m in graph[n]:
            indeg[m] -= 1
            if indeg[m] == 0:
                queue.append(m)
    if len(order) != len(graph):
        raise ValueError("Cycle detected")
    return order
```

Builds an in-degree map over the dependency graph, peels off zero-in-degree nodes with a queue, and raises `ValueError` if any nodes remain (indicating a cycle).
