# task 7: Write a Python generator that yields sliding-window averages over an iterable of numbers.

```python
from collections import deque

def sliding_average(iterable, window):
    if window <= 0:
        raise ValueError("window must be positive")
    buf = deque(maxlen=window)
    total = 0.0
    for x in iterable:
        if len(buf) == window:
            total -= buf[0]
        buf.append(x)
        total += x
        if len(buf) == window:
            yield total / window
```

Maintains a fixed-size deque and running sum so each yielded average costs O(1); only full windows are emitted.
