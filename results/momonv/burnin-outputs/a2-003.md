# task 9: Write a Python dataclass-based bank account with deposit, withdraw and a transaction history, raising on overdraft.

```python
from dataclasses import dataclass, field
from typing import List, Tuple


@dataclass
class BankAccount:
    owner: str
    balance: float = 0.0
    history: List[Tuple[str, float, float]] = field(default_factory=list)

    def deposit(self, amount: float) -> None:
        if amount <= 0:
            raise ValueError("Deposit must be positive")
        self.balance += amount
        self.history.append(("deposit", amount, self.balance))

    def withdraw(self, amount: float) -> None:
        if amount <= 0:
            raise ValueError("Withdrawal must be positive")
        if amount > self.balance:
            raise ValueError("Insufficient funds (overdraft)")
        self.balance -= amount
        self.history.append(("withdraw", amount, self.balance))
```

The dataclass tracks owner, balance, and a history of `(type, amount, resulting_balance)` tuples; `withdraw` raises `ValueError` on overdraft or non-positive amounts.
