# task 1: Write a Python LRU cache class with get and put in O(1), without functools.

```python
from collections import OrderedDict

class LRUCache:
    def __init__(self, capacity):
        self.capacity = capacity
        self.cache = OrderedDict()

    def get(self, key):
        if key not in self.cache:
            return -1
        self.cache.move_to_end(key)
        return self.cache[key]

    def put(self, key, value):
        if key in self.cache:
            self.cache.move_to_end(key)
        self.cache[key] = value
        if len(self.cache) > self.capacity:
            self.cache.popitem(last=False)
```

`OrderedDict` gives O(1) lookups, moves, and evictions, so both operations run in constant time. `move_to_end` marks a key as most recently used, and `popitem(last=False)` evicts the least recently used entry.
