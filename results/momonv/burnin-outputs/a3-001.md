# task 0: Write a Python function that merges overlapping intervals. Include a short docstring.

```python
def merge_intervals(intervals):
    """Merge overlapping [start, end] intervals; returns a new sorted list."""
    merged = []
    for start, end in sorted(intervals):
        if merged and start <= merged[-1][1]:
            merged[-1][1] = max(merged[-1][1], end)
        else:
            merged.append([start, end])
    return merged
```

Sorting by start makes any overlap detectable against the last merged interval, and extending its end in place keeps the merge O(n log n).
