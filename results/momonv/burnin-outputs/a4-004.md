# task 6: Write a Python function that topologically sorts a dependency dict and raises on cycles.

```python
def topological_sort(graph):
    visited, order = set(), []
    def visit(node, stack):
        if node in stack:
            raise ValueError(f"cycle detected at {node!r}")
        if node in visited:
            return
        stack.add(node)
        for dep in graph.get(node, ()):
            visit(dep, stack)
        stack.discard(node)
        visited.add(node)
        order.append(node)
    for node in graph:
        visit(node, set())
    return order
```

The DFS adds a node to `order` only after all its dependencies, so reversing the result gives a valid topological order; a node appearing on the current recursion stack signals a cycle.
